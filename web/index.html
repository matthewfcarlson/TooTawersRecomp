Keys (click the picture first: that also starts the sound)

WASD move · K A (jump) · J X (fast attack) · I Y (fierce attack) · L B (parry) · F/R left/right trigger · Enter Start · Backspace Back · arrows: d-pad

Controllers (Xbox, PlayStation, Switch Pro, …) work too: press a button on one so the browser shows it.

Settings go in the address: ?TT_TWEAKS=SKIPMAINMENU=1;HERO=aragorn;LEVEL=01WEAT1 starts in the first level. Any KEY=VALUE becomes one of the game's switches.
